# วิธีติดตั้ง Google AdSense บน KidHai

โค้ดฝั่งแอปเตรียมพื้นที่โฆษณาและสคริปต์ไว้ให้พร้อมแล้ว สิ่งที่เหลือคือการไปสมัคร Google AdSense
เอง (ต้องใช้บัญชี Google ของคุณ) แล้วนำ **Publisher ID** และ **Ad Slot ID** มาใส่ในไฟล์ `.env.local`
เท่านั้น ไม่ต้องแก้โค้ดเพิ่ม

## ภาพรวมของระบบที่เตรียมไว้ให้แล้ว

| ไฟล์ | หน้าที่ |
|---|---|
| [`src/lib/site.ts`](../src/lib/site.ts) | อ่านค่า Publisher ID / Slot ID จาก environment variables |
| [`src/app/layout.tsx`](../src/app/layout.tsx) | โหลดสคริปต์ `adsbygoogle.js` ของ Google อัตโนมัติ **เฉพาะเมื่อตั้งค่า Publisher ID แล้ว** |
| [`src/components/ads/AdSlot.tsx`](../src/components/ads/AdSlot.tsx) | คอมโพเนนต์แสดงโฆษณา 1 ตำแหน่ง — ถ้ายังไม่ตั้งค่าจะโชว์กรอบ placeholder แทนโดยอัตโนมัติ (ไม่มีข้อผิดพลาด ไม่กระทบ UI) |
| [`.env.example`](../.env.example) | ตัวอย่างชื่อตัวแปรที่ต้องตั้งค่า |

ตำแหน่งโฆษณาที่วางไว้ในเว็บ (ออกแบบให้ไม่รบกวนผู้ใช้จนเกินไป ไม่มี popup/interstitial):

1. **Sidebar** (จอ desktop เท่านั้น) — การ์ดสี่เหลี่ยมด้านล่างเมนู
2. **Top banner** — แถบยาวด้านบนเนื้อหาของแต่ละเครื่องมือ
3. **In-content** — คั่นระหว่างส่วนตั้งค่ากับผลลัพธ์ ในทั้ง 3 เครื่องมือ (ข้อมูลบุคคล/บัตรเครดิต/ไฟล์) และใต้ FAQ ท้ายหน้า

รวมทั้งหมด ~5-6 ตำแหน่งต่อการเข้าใช้งาน 1 ครั้ง (นับตามแท็บที่เปิด) ซึ่งอยู่ในระดับที่ Google
แนะนำสำหรับเว็บแอปที่มีเนื้อหา/ฟีเจอร์เยอะ โดยไม่ถือเป็นการยัดโฆษณาจนน่ารำคาญ (ดูหัวข้อ
"นโยบายที่ต้องระวัง" ด้านล่าง)

---

## ขั้นตอนที่ 1 — สมัคร Google AdSense

1. ไปที่ https://www.google.com/adsense/ แล้วกด **เริ่มต้นใช้งาน** ด้วยบัญชี Google ของคุณ
2. กรอก URL เว็บไซต์ของคุณ เช่น `https://kidhai.phumrapee.com`
3. เลือกประเทศ/ภูมิภาค และยอมรับเงื่อนไขการให้บริการ
4. Google จะให้โค้ดสำหรับ "ยืนยันความเป็นเจ้าของเว็บไซต์" มาในรูปแบบ
   `<meta name="google-adsense-account" content="ca-pub-XXXXXXXXXXXXXXXX">`
   **ไม่ต้องแก้โค้ดเอง** — แค่นำเลข `ca-pub-XXXXXXXXXXXXXXXX` ไปใส่ในขั้นตอนที่ 2 ระบบจะแทรก
   meta tag นี้ให้อัตโนมัติ (ดูใน `src/app/layout.tsx`)
5. กด "ยืนยัน" ฝั่ง Google Search Console หรือรอให้ระบบตรวจสอบ (โดยทั่วไปใช้เวลา 1 วัน – 2 สัปดาห์
   กว่าจะอนุมัติ ระหว่างนี้เว็บของคุณต้องเข้าถึงได้จริงบนอินเทอร์เน็ต และมีเนื้อหาครบตามนโยบาย)

## ขั้นตอนที่ 2 — ตั้งค่า Publisher ID ในโปรเจกต์

1. คัดลอกไฟล์ `.env.example` เป็น `.env.local`:

   ```bash
   cp .env.example .env.local
   ```

2. เปิด `.env.local` แล้วใส่ Publisher ID ที่ได้จากขั้นตอนที่ 1:

   ```bash
   NEXT_PUBLIC_ADSENSE_CLIENT_ID=ca-pub-XXXXXXXXXXXXXXXX
   ```

3. รัน `npm run dev` ใหม่ — ถ้าใส่ถูกต้อง สคริปต์ AdSense จะถูกโหลดอัตโนมัติ (ดูได้จาก Network tab
   ว่ามีการเรียก `pagead2.googlesyndication.com`)

> เมื่อ deploy จริง (เช่น Vercel/Netlify) ต้องไปตั้งค่า environment variable ตัวเดียวกันนี้ในหน้า
> ตั้งค่าโปรเจกต์ของ hosting ด้วย ไม่ใช่แค่ในเครื่อง

## ขั้นตอนที่ 3 — สร้าง Ad Unit และนำ Slot ID มาใส่

1. ในหน้า AdSense dashboard ไปที่ **โฆษณา → ตามหน่วยโฆษณา → สร้างหน่วยโฆษณาใหม่**
2. แนะนำให้สร้าง 3 หน่วยโฆษณาแบบ **Display ads (แบบตอบสนองอัตโนมัติ/Responsive)**:
   - `top-banner` — ใช้ layout แนวนอน (Horizontal)
   - `sidebar` — ใช้ layout สี่เหลี่ยม (Rectangle)
   - `in-content` — ใช้ layout แนวนอน หรือ In-article
3. หลังสร้างเสร็จ Google จะให้ `data-ad-slot="XXXXXXXXXX"` มาต่อหน่วย — คัดลอกตัวเลขนั้น
4. ใส่ลงใน `.env.local`:

   ```bash
   NEXT_PUBLIC_ADSENSE_SLOT_TOP_BANNER=XXXXXXXXXX
   NEXT_PUBLIC_ADSENSE_SLOT_SIDEBAR=XXXXXXXXXX
   NEXT_PUBLIC_ADSENSE_SLOT_IN_CONTENT=XXXXXXXXXX
   ```

5. รีสตาร์ท dev server / deploy ใหม่ — ตำแหน่ง placeholder จะเปลี่ยนเป็นโฆษณาจริงทันที (อาจใช้เวลา
   สักครู่กว่าโฆษณาชุดแรกจะโหลดขึ้นมา โดยเฉพาะช่วงแรกที่บัญชียังใหม่)

หากไม่อยากแยก slot ตามตำแหน่ง จะใช้ slot เดียวกันทั้งหมดก็ได้ (ใส่เลขเดียวกันในทั้ง 3 ตัวแปร)
แต่แยกกันจะช่วยให้ดูรายงานผลตอบแทนต่อตำแหน่งได้ละเอียดกว่าใน AdSense dashboard

## ขั้นตอนที่ 4 — ทำไฟล์ `ads.txt` (สำคัญ ไม่ควรข้าม)

Google กำหนดให้เว็บที่รับโฆษณาต้องมีไฟล์ `ads.txt` ที่ root ของโดเมน มิฉะนั้นรายได้อาจลดลงหรือ
โฆษณาบางส่วนไม่แสดง สร้างไฟล์ `public/ads.txt` ในโปรเจกต์นี้:

```
google.com, pub-XXXXXXXXXXXXXXXX, DIRECT, f08c47fec0942fa0
```

แทน `pub-XXXXXXXXXXXXXXXX` ด้วย Publisher ID เดียวกับขั้นตอนที่ 2 (ตัด `ca-` ออก) ไฟล์นี้จะถูก
เสิร์ฟที่ `https://kidhai.phumrapee.com/ads.txt` โดยอัตโนมัติเพราะ Next.js เสิร์ฟทุกไฟล์ใน `public/`
ที่ root path

## ขั้นตอนที่ 5 — Consent Mode (ผู้ใช้งานในสหภาพยุโรป/UK)

ถ้าคาดว่าจะมีผู้ใช้จากสหภาพยุโรป (EEA), สหราชอาณาจักร, หรือสวิตเซอร์แลนด์ Google กำหนดให้ต้องขอ
ความยินยอม (consent) ก่อนแสดงโฆษณาแบบ personalized ตาม GDPR วิธีที่ง่ายที่สุดคือเปิดใช้
**Google Funding Choices / Privacy & messaging** ในหน้า AdSense dashboard
(เมนู "ความเป็นส่วนตัวและการส่งข้อความ") ระบบจะแทรก consent banner ให้อัตโนมัติโดยไม่ต้องแก้โค้ด
เพิ่มเติมในโปรเจกต์นี้ (สคริปต์จะทำงานร่วมกับ `adsbygoogle.js` ที่โหลดอยู่แล้ว)

## นโยบายที่ต้องระวัง (สำคัญมาก เพื่อไม่ให้บัญชีถูกระงับ)

- **ห้ามกดโฆษณาของตัวเอง หรือขอให้คนอื่นกดให้** (invalid traffic) — เป็นสาเหตุอันดับ 1 ที่บัญชีถูก
  แบน แม้แต่การบอกเพื่อน/ทีมให้ "ช่วยกดโฆษณาหน่อย" ก็ผิดนโยบาย
- **ห้ามใช้ popup, interstitial, หรือโฆษณาที่บังเนื้อหาจนกดปิดไม่ได้** — โค้ดในโปรเจกต์นี้ออกแบบ
  มาไม่ให้ทำแบบนั้นอยู่แล้ว (ทุกตำแหน่งเป็น in-flow ไม่ลอยทับเนื้อหา)
  ระวังอย่าเพิ่มโฆษณาแบบ anchor/vignette เองในอนาคตโดยไม่ตรวจนโยบายก่อน
- **เนื้อหาเว็บไซต์ต้องมีสาระจริง** (มีหน้า FAQ, คำอธิบายการใช้งานอยู่แล้วในหน้าแรกเพื่อรองรับข้อนี้)
- **จำนวนโฆษณาต่อหน้าไม่ควรเยอะกว่าเนื้อหา** — ตำแหน่งที่วางไว้ให้ (5-6 จุด กระจายตามแท็บ) อยู่ใน
  เกณฑ์ที่เหมาะสมแล้ว ไม่แนะนำให้เพิ่มมากกว่านี้ในหน้าเดียว
- ห้ามวางโฆษณาไว้ใกล้ปุ่มที่ผู้ใช้กดบ่อย (เช่น ปุ่ม "สุ่มข้อมูลใหม่") จนอาจกดพลาด — ตำแหน่งที่จัดไว้
  เว้นระยะห่างจากปุ่มสำคัญแล้ว

## การทดสอบ

- ระหว่างพัฒนา (`NODE_ENV !== production`) โค้ดจะส่ง `data-adtest="on"` ให้อัตโนมัติ เพื่อไม่ให้
  ยิง impression/click จริงตอนทดสอบ (ป้องกัน invalid traffic โดยไม่ตั้งใจ)
- โฆษณาจริงจะไม่แสดงจนกว่าบัญชี AdSense จะได้รับการอนุมัติ — ระหว่างรออนุมัติ ตำแหน่งต่างๆ จะ
  แสดง placeholder กรอบประ "พื้นที่โฆษณา (Google AdSense)" แทน ซึ่งเป็นพฤติกรรมปกติ
- ถ้าใช้ ad blocker ในเบราว์เซอร์ตอนทดสอบ จะไม่เห็นโฆษณาเช่นกัน ลองปิด extension หรือเปิด
  Incognito โดยไม่ลง extension เพื่อทดสอบ

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ |
|---|---|
| ไม่เห็นโฆษณาเลย ขึ้น placeholder ตลอด | ยังไม่ได้ตั้ง `NEXT_PUBLIC_ADSENSE_CLIENT_ID` หรือ slot ID ใน `.env.local` แล้ว restart dev server หรือ deploy ใหม่ |
| ตั้งค่าแล้วแต่ยังไม่ขึ้นโฆษณาจริง | บัญชียังไม่ผ่านการอนุมัติ หรือเพิ่งตั้งค่าไป (รอ 30 นาที – 2 ชั่วโมงให้ระบบ Google sync) |
| เว็บดูมีพื้นที่ว่างกระโดดตอนโฆษณาโหลด (layout shift) | ปรับ prop `minHeight` ใน `<AdSlot />` ให้ใกล้เคียงขนาดจริงของหน่วยโฆษณาที่สร้างไว้ |
| รายได้น้อยผิดปกติ / โฆษณาไม่ผ่าน review | ตรวจสอบว่าทำไฟล์ `public/ads.txt` แล้ว และ Publisher ID ตรงกันทุกจุด |
